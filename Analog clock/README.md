# 🕒 Analog Clock using HTML, CSS & JavaScript

---

##  Overview  
This project is a simple and interactive Analog Clock built using **HTML, CSS, and JavaScript**.  
It displays the current time with moving hour, minute, and second hands in real-time.

---

##  Objectives  

- Build a real-time clock using JavaScript  
- Understand DOM manipulation  
- Practice CSS styling and transformations  
- Learn how time functions work in JavaScript  

---

##  Technologies Used  

-  HTML (Structure)  
-  CSS (Styling & Layout)  
-  JavaScript (Logic & Functionality)  

---

## Features  

-  Real-time clock updates every second  
-  Smooth rotation of hour, minute, and second hands  
-  Responsive and clean UI  
-  Minimal and modern design  

---

##  Concepts Covered  

- ***Date()*** object in JavaScript  
- ***setInterval()*** for real-time updates  
- DOM manipulation using ***querySelector***  
- CSS ***transform: rotate()*** for hand movement  

---

##  Project Structure  

```bash
Analog-Clock/
│
├── index.html     # Structure of the clock
├── style.css      # Styling and layout
├── script.js      # Clock logic
└── README.md      # Documentation
```

---

## 💡 How It Works  

- JavaScript fetches the current time using ***Date()***  
- Converts hours, minutes, and seconds into degrees  
- Applies rotation using CSS ***transform***  
- Updates every second using ***setInterval()***  

---

##  Output  

A working analog clock showing real-time updates with rotating hands.
